# 🥗 AI Vision Nutrition Chatbot

An intelligent diet and nutrition assistant powered by Computer Vision and AI. The application allows users to snap/upload meal photos to get real-time macronutrient estimates, clarify dietary questions, and connect directly with nutrition support via WhatsApp.

🔗 **Live Demo:** [AI Vision Nutrition Chatbot](https://ai-vision-nutrition-chatbot-bzuhdevnycau3evmmsprnn.streamlit.app/)

---

## 🚀 Key Features

- **Snap & Analyze (Vision AI):** Upload a meal photo to get an instant breakdown of calories, proteins, carbohydrates, fats, and essential micronutrients.
- **Interactive Dietary Q&A:** Ask follow-up questions to understand portion control, alternative meal ideas, or allergen warnings.
- **Direct WhatsApp Integration:** Seamlessly reach out via WhatsApp for personalized guidance and ongoing health consultations.
- **Clean & Fast UI:** Built with Streamlit for a fast, responsive, and user-friendly experience.

---

## 🛠️ Tech Stack

- **Frontend / Framework:** [Streamlit](https://streamlit.io/)
- **AI / Vision Model:** Google Gemini API (Multimodal Vision)
- **Programming Language:** Python 3.10+
- **Version Control & Deployment:** Git, GitHub, Streamlit Community Cloud
